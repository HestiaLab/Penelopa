## 3. 领域模型

### 3.1 Primitive 基类

```csharp
public abstract class Primitive : IAlignable
{
    public Guid Id { get; internal set; }
    public StringPropValue Name { get; }
    public IReadOnlyList<PropValue> Props { get; }
    public Primitive? Parent { get; internal set; }
    internal PrimitiveService? Owner { get; }

    public Box GetWorldBoundingBox();
    public void Translate(float deltaX, float deltaY);
    public Box SetBounds(Box bounds, Point anchor);
    public bool CanResizeInWorld { get; }
    public bool ContainsWorldPoint(Point point);
    public Point GetWorldPosition();
    public void SetWorldPosition(Point position);

    protected abstract Box GetLocalBoundingBox();
    protected abstract void TranslateLocal(float deltaX, float deltaY);
    protected abstract Box SetBoundsLocal(Box bounds, Point anchor);
    protected abstract bool ContainsLocalPoint(Point point);
}
```

约定：

- 构造函数生成新 `Guid`，并注册名称属性（非空、≤128 字符、去空白）。
- `Props` 是只读视图，属性只在构造期通过 `AddProp` 注册。
- `GetWorldBoundingBox` 取局部包围盒，沿父容器链逐级 `TransformBoundsToParent`。
- `Translate` 在存在父容器时先把世界增量转换为父局部向量，再调用 `TranslateLocal`。
- `SetBounds` 是世界空间唯一入口：有父容器时，把世界包围盒与锚点各转换一次到父局部空间，调用 `SetBoundsLocal`，再把结果转回世界。
- `CanResizeInWorld` 从自身向上检查容器 `LocalTransform.IsAxisAligned`；任一祖先含旋转/剪切即为 false。
- `ContainsWorldPoint` 把世界点转换到自身或父容器的局部空间后调用形状测试。
- 世界锚点为 `(MinX, MaxY)`，对应屏幕左上角（世界 Y 向上，屏幕 Y 向下）。
- `Owner` 由 `PrimitiveService` 维护；容器结构变更时递归设置，用于拒绝跨文档挂载。

### 3.2 叶子图元

| 类型 | 属性与默认值 | 局部包围盒 | 命中测试 |
| --- | --- | --- | --- |
| `Circle` | `CenterX=10`、`CenterY=10`、`Radius=5`（>0）、`Color=0xFFFFFFFF` | 中心 ± 半径 | 平方距离 ≤ 半径² |
| `Rectangle` | `PosX=10`、`PosY=10`、`Width=10`（>0）、`Height=10`（>0）、`Color` | `(PosX,PosY)-(PosX+Width,PosY+Height)` | 闭区间 AABB |
| `Triangle` | 六个顶点默认 `(50,50)(70,50)(60,60)`、`Color` | 三顶点最小/最大 | 三边叉积同号（含边界）；零面积不可命中 |

`SetBoundsLocal` 规则：

- 圆：`r = max(0, min(bounds.Width, bounds.Height)/2)`；根据锚点落在目标框左/右、下/上边界，把圆心放在距对应边 `r` 处，保持宽高比；返回实际局部包围盒。调用方需用返回值修正选区框。
- 矩形：直接写入 `PosX/PosY/Width/Height`，返回目标框。
- 三角形：按各顶点在当前局部包围盒中的归一化坐标线性映射到目标框，保持形状并填满目标框。
- 容器：见 3.3。

### 3.3 Container

```csharp
public sealed class Container : Primitive
{
    public ContainerKind Kind { get; }              // Offset / Rotation / Flip
    public FloatPropValue OffsetX, OffsetY, Rotation, ScaleX, ScaleY;
    public Transform LocalTransform { get; }
    public IReadOnlyList<Primitive> Children { get; }

    public static Container CreateOffset(string name, float offsetX, float offsetY);
    public static Container CreateRotation(string name, float degrees);
    public static Container CreateFlip(string name, bool flipX, bool flipY);

    public void AddChild(Primitive child);
    public void RemoveChild(Primitive child);
    public Box TransformBoundsToParent(Box local);
    public Box ToLocalBounds(Box parent);
    public Box WorldToLocalBounds(Box world);
    public Box ToWorldBounds(Box local);
    public Point ToLocalVector(float worldDx, float worldDy);
    public Point ToLocalPoint(Point world);
}
```

- `ContainerKind` 只决定属性面板暴露的属性：Offset 暴露 `OffsetX/OffsetY`，Rotation 暴露 `Rotation`，Flip 暴露 `ScaleX/ScaleY`；所有属性始终存在并参与变换。
- `LocalTransform = Translate(OffsetX, OffsetY) · Rotate(Rotation) · Scale(ScaleX, ScaleY)`，矩阵mul 语义为“先应用右侧”，即先缩放、再旋转、再平移。
- 生效缩放幅值钳位到 `≥0.01`（保留符号），避免奇异矩阵；原始属性值不被改写。
- `AddChild` 拒绝已有父级、跨文档、自身/后代循环（循环由服务层校验）；只允许一个父级。
- `RemoveChild` 把子项脱离到根级并清除文档归属。
- `GetLocalBoundingBox = TransformBox(并集(子项局部包围盒), LocalTransform)`；空容器为 `(0,0,0,0)`。
- `SetBoundsLocal`：
  - `sx = target.Width/current.Width`、`sy = target.Height/current.Height`；当前尺寸近零时比例为 1；比例幅值至少 0.01。
  - 旋转/翻转容器把 `sx/sy` 统一为绝对值较小者并保留各自符号，避免注入剪切。
  - 锚点保持不动：`deltaX = anchor.X - anchor.X*sx`，`OffsetX = deltaX + OffsetX*sx`；Y 同理；`ScaleX *= sx`、`ScaleY *= sy`。
- `ToLocalVector/ToLocalPoint` 沿祖先链逐级求逆；`ToWorldBounds` 沿链逐级正向变换。

### 3.4 属性类型

| 类型 | 文本规则 | 领域规则 |
| --- | --- | --- |
| `IntPropValue` | 整数（InvariantCulture） | — |
| `FloatPropValue` | 浮点数（InvariantCulture） | 有限；`|v| ≤ 1e7`；可选 exclusiveMinimum / minimum / maximum |
| `DoublePropValue` | 浮点数 | 有限；`|v| ≤ 1e7` |
| `BoolPropValue` | `true`/`false` | — |
| `StringPropValue` | 原文本 | 可配置非空、最大长度、trim |
| `UintPropValue` | 无符号整数 | 0..4294967295 |
| `ColorPropValue` | `#RRGGBB` 或 `#RRGGBBAA`（可省略 `#`） | 内部 `0xAARRGGBB`；6 位默认 A=255 |

`PropValue.GetBoxedValue/SetBoxedValue` 支持上述七种类型与 `JsonElement` 回读；未知子类型抛出 `NotSupportedException`，防止历史或序列化静默丢属性。`ColorPropValue.ToHex()` 统一输出 `#RRGGBBAA`。

### 3.5 坐标与变换

`Transform` 为 3×3 列向量矩阵 `|a c tx; b d ty; 0 0 1|`：

- `Rotate(degrees)` 使用角度制，`cos/sin`；`Scale` 绕原点；`Translate` 为平移。
- `Multiply(other)` 表示 `this ∘ other`，先应用 `other`。
- `Invert()` 在行列式绝对值 `<1e-6` 时抛出；否则按标准伴随矩阵求逆。
- `ApplyToPoint` 含平移；`ApplyToVector` 只含线性部分。
- `IsAxisAligned` 要求 `|B|,|C| < 1e-6`；`IsIdentity` 要求六分量在 `1e-4` 内等于单位阵。
- 对齐参考为选中项世界 AABB 并集；容差 `1e-6`。`Top` 使用 `MaxY`、`Bottom` 使用 `MinY`，因为屏幕 y 向下。
- 对齐只通过 `SetWorldPosition` 平移；`GetWorldPosition` 返回 `(MinX, MaxY)`，`SetWorldPosition` 通过 `Translate` 到达目标锚点。

## 4. 文档服务与历史

### 4.1 IPrimitiveService 契约

| 方法 | 语义 |
| --- | --- |
| `Add(Primitive)` | 只接受根图元；拒绝跨文档、重复、非法属性；一个事务。 |
| `AddToContainer(Container, Primitive)` | 只接受根子项；拒绝自身、跨文档、已有父级、祖先移入后代；一个事务。 |
| `GroupSelection(out error)` | ≥2 个根级选中项；identity Offset 容器；插入到第一个选中根的位置；选择新容器；一个事务。 |
| `TryUngroup(Container, out error)` | 仅根级 identity 容器；子项按原顺序回根列表并选中；一个事务。 |
| `RemoveRange(IEnumerable)` | 批量删除，一个事务；清理失效选区。 |
| `ReplaceAll(roots, clearHistory=true)` | 安装新根列表、重设 Owner、清空选区；可清空历史。 |
| `BeginTransaction/CommitTransaction/CancelTransaction` | 事务边界；取消恢复事务前快照。 |
| `Align(AlignType)` | ≥2 项；无变化则丢弃事务；否则提交并通知 Geometry。 |
| `TrySetProperty(owner, property, text, out error)` | 校验属性归属；委托批量重载。 |
| `TrySetProperty(owners, propertyName, text, out error)` | 同名同类型；先存旧值；逐项校验；失败全部回滚；无变化丢弃事务；成功一个条目。 |
| `MoveSelection(dx, dy)` | 世界增量移动选区；零位移不产生条目。 |
| `SetSelected/SetSelectedRange/AppendSelected/ClearSelection` | 统一规范化后的选区写入口。 |
| `CaptureHistoryState/RestoreHistoryState` | 供导入回滚捕获/恢复文档、撤销/重做栈。 |
| `NotifyPrimitivesChanged/NotifyTransientValuesChanged` | 通知几何变化 / 仿真临时值恢复（Transient 不清除导入回滚）。 |
| `Changed` | `DocumentChange(Kind, State)`；Kind 可组合 Structure/Selection/Geometry/Transient。 |

选区规范化：所有入口先去重，再剔除“存在已选中祖先”的后代。根列表与选区对外返回副本。

### 4.2 事务与快照

`DocumentHistory` 状态：`_undoStack`、`_redoStack`、`_pending`、`_depth`。

| 操作 | 行为 |
| --- | --- |
| `BeginTransaction` | 深度 0 时捕获快照并置深度 1；嵌套只增加深度。 |
| `CommitTransaction` | 深度减 1；归零时把 pending 压入撤销栈并清空重做栈。 |
| `CancelTransaction` | 深度归零，应用 pending 快照。 |
| `DiscardTransaction` | 深度归零，丢弃 pending，不恢复（无实际变化时使用）。 |
| `Undo` | 事务中或栈空时无操作；捕获当前快照压入重做栈，应用撤销栈顶。 |
| `Redo` | 对称操作。 |
| `CaptureState` | 事务中抛异常；返回当前快照与两个栈的副本。 |
| `RestoreState` | 事务中抛异常；恢复文档与两个栈。 |

`DocumentSnapshot` 内容：根列表、每图元按名称装箱的属性值、每个容器的子项列表。`Apply` 顺序：

1. 从快照的子项关系重建节点集合（不遍历活跃树）。
2. 计算快照中的父子关系；把节点从当前不匹配的父级摘下（撤销分组时必须解除旧父指针）。
3. 按快照恢复每个容器的子项，先清 Owner，再 `AddChild`。
4. 记录当前活跃选区；`ReplaceAll(clearHistory:false)` 重建根列表并清空选区。
5. 恢复所有属性值。
6. 重新应用仍存在于快照中的活跃选区。

### 4.3 分组与取消分组

- 分组条件：选中项 ≥2、全部为文档根、都属于当前文档。顺序按根列表顺序；插入索引为第一个选中根在移除前的索引。
- 分组事务内：从根列表移除选中项 → 插入 identity Offset 容器 → 设置 Owner → 依次 `AddChild` → 选区只含新容器。
- 取消分组条件：单选、根级、属于当前文档、`LocalTransform.IsIdentity`（允许浮点误差 1e-4）。
- 取消分组事务内：从容器移除全部子项 → 从根列表移除容器并清 Owner → 在容器原索引插入子项 → 重设 Owner → 选区为全部子项。
- 两者失败都在事务前返回，不改变文档；成功后一次 `Structure|Selection` 通知。

## 5. 交互与渲染

### 5.1 手势状态机

`EditorInteractionController` 状态：`Idle`、`Pressed`、`Dragging`、`Resizing`。

- `PointerDown`：
  - 命中角柄且存在目标 → `Resizing`，记录原始世界包围盒与手柄。
  - 命中图元且 Ctrl/Meta → 追加最外层候选；已选中则切换移除，结束。
  - 命中图元且已选中且多选 → `Pressed`，延迟到松开决定“单击折叠 / 拖拽整组”。
  - 命中图元 → 解析钻取目标并单选，`Pressed`。
  - 命中多选并集框 → `Pressed`，用于整组拖拽。
  - 空白 → 清空选择，`Pressed` 并标记可能转平移。
- `PointerMove`：`Pressed` 中位移超过 3 世界单位 → 开始拖拽；空白来源则平移视口，否则移动选区。`Resizing` 中计算新包围盒并 `SetBounds`。
- `PointerUp`：延迟的单击折叠选择；拖拽/缩放提交事务并通知一次。
- `Cancel`：若已捕获变更，取消事务（恢复快照），再通知受影响图元；`pointercancel`、失去捕获、窗口失焦、页面隐藏均触发。
- 钻取：命中候选链为“根→最深叶子”；同一链、同一位置（4 世界单位内）、500ms 内连续点击推进索引，否则从最外层开始。
- 拖拽首次真实修改前调用 `BeginMutation`；从按下点计算全量位移，避免从阈值处才开始移动。

### 5.2 缩放数学

`ResizeMath.ComputeBounds(original, handle, pointer)`：

1. 固定角为被拖手柄的对角。
2. 新框为固定角与指针的 min/max；宽或高小于 1 时锚定固定角扩展到 1。
3. 拖过固定角自然产生镜像（min/max 交换符号）。
4. 图元 `SetBounds` 负责世界→父局部转换；圆保持比例并用返回框修正覆盖层；三角形按归一化顶点映射。

### 5.3 视口与坐标换算

`ViewTransform` 字段：`ViewWidth/ViewHeight`（物理像素）、`DevicePixelRatio`、`Zoom`、`PanX/PanY`（CSS 像素）。

```
WorldToView(x,y) = (W/2 + (PanX + x*Zoom)*DPR, H/2 + (PanY - y*Zoom)*DPR)
ViewToWorld(vx,vy) = ((vx - W/2)/DPR - PanX)/Zoom, ((H/2 - vy)/DPR + PanY)/Zoom
ScreenToView(sx,sy) = (sx*DPR, sy*DPR)
ApplyTo(canvas) = Translate(W/2 + PanX*DPR, H/2 + PanY*DPR); Scale(DPR*Zoom, -DPR*Zoom)
```

- 缩放围绕 CSS 指针：先求指针下世界点，再反解新的 `PanX/PanY`。
- Fit：`zoom = min(viewportW/(contentW+2p), viewportH/(contentH+2p))`，夹取 `0.05..4`，`Pan = (-centerX*zoom, centerY*zoom)`。
- 尺寸/DPR 变化保留 `Zoom/Pan`；`EnsureView` 只更新宽高与 DPR。

### 5.4 颜色键命中

- 键范围 `0xFF000001..0xFFFFFFFF`（黑色背景 `0xFF000000` 保留）；单帧容量约 1677 万。
- 每帧 `BeginFrame` 清空映射并把 64 位游标复位到首键；`Register` 分配并登记；越界抛 `InvalidOperationException`。
- 可见画布使用抗锯齿填充；命中画布使用非抗锯齿填充，避免边缘混色。
- 命中流程：CSS → 视口像素 → 读取命中位图颜色 → 映射图元；越界返回 null。
- 分层命中：单选角柄（最高）→ 图元颜色键 → 多选并集框（最低）。`PickAll` 返回命中叶子及其祖先链并反转为根→叶子。

### 5.5 渲染与覆盖层

- `CanvasRenderer.Render`：确保缓冲尺寸 → 清黑 → `ScenePainter.Paint` → 把位图绘到目标 → 绘制选区覆盖层。
- `ScenePainter` 先以屏幕空间画坐标轴（不进入命中缓冲），再以世界矩阵绘制图元树；容器递归 concat 变换；渲染顺序即 Z 序。
- 仿真只读路径传 `renderHitBuffer=false`、`drawAxes=false`，跳过命中画布与坐标轴。
- 选区覆盖层：轮廓 1.5/zoom 世界单位（屏幕固定）；角柄 8 CSS 像素，位置为世界 AABB 四角；仅单选且 `CanResizeInWorld` 时绘制角柄。
- 角柄命中半径：短边屏幕尺寸的 20%，夹取 `1.5..5` CSS 像素；多选并集框用投影 AABB 命中。
- DPR 由宿主从 `SKGLView` 的 `Info` 提供；`IgnorePixelScaling=false` 时是物理像素。渲染器不自行读取窗口 DPR，避免与组件生命周期耦合。

## 6. 仿真引擎

### 6.1 数据模型

```csharp
public sealed record SimulationConfig(bool Loop, IReadOnlyList<SimulationTrack> Tracks);
public sealed record SimulationTrack(Guid PrimitiveId, string PropertyName, IReadOnlyList<SimulationKeyframe> Keyframes);
public readonly record struct SimulationTrackKey(Guid PrimitiveId, string PropertyName);
public sealed record SimulationKeyframe(double Time, float Value, InterpolationKind Interpolation, CubicBezier? Bezier);
```

约束：轨道至少 1 个关键帧；同一 `(PrimitiveId, PropertyName)` 至多一条；`cubic-bezier` 必须带控制点，非 `cubic-bezier` 不得带控制点；配置与轨道构造时复制集合，实例不可变。

### 6.2 解析与求值

- `SimulationPrimitiveIndex.Create(roots)`：深度优先收集根与容器后代，建立 Id 字典与 Float 属性列表；重复 Id 抛异常。
- `SimulationResolver.Resolve(config, index)`：目标图元存在且属性仍为 `FloatPropValue` → Active；否则 Dormant。
- `SimulationEvaluator.Evaluate(track, time)`：
  - `time <= first.Time` 取首值；`time >= last.Time` 取末值。
  - 否则二分查找最后一个 `Time <= time` 的 `lower`，`upper = lower+1`。
  - `step` 返回 `lower.Value`；`span <= 0` 返回 `upper.Value`。
  - `progress = (time - lower.Time)/span`；`eased = Ease(progress, lower)`；`value = lower.Value + (upper.Value - lower.Value)*eased`。
- `Ease`：linear 为 `u`；ease-in/out/in-out 使用预设贝塞尔；step 为 0；cubic-bezier 使用自定义控制点；结果夹取 `[0,1]`。
- 贝塞尔预设：ease-in `(0.42,0,1,1)`、ease-out `(0,0,0.58,1)`、ease-in-out `(0.42,0,0.58,1)`。
- `CubicBezierSolver.Evaluate`：对 `x(t) = 3(1-t)²t·x1 + 3(1-t)t²·x2 + t³` 做 32 次二分反解 `t`，再求 `y(t)`；端点直接返回 0/1；结果夹取 `[0,1]`。控制点在 `[0,1]` 内保证 x(t) 单调。

### 6.3 时间轴

- `GetDuration(tracks)`：所有轨道最后一个关键帧时间的最大值；空集合为 0。
- `Clamp(time, duration)`：非有限参数抛异常；`duration <= 0` 返回 0；否则夹取 `[0,duration]`。
- `Wrap(time, duration)`：`duration <= 0` 返回 0；否则取正模。
- `Step(time, delta, duration)`：先加再夹取。

### 6.4 校验

`SimulationValidator.ValidateStructure(config)` 检查：

- 轨道数 ≤2000；总关键帧数 ≤10000。
- 轨道 Id 非空、属性名非空、`(Id, Property)` 不重复。
- 单轨关键帧数 ≤200；每条轨道至少由模型保证 1 帧。
- 每帧时间有限、`0..3600`；相邻时间差 ≥1ms（前一时间非法时重置比较基准）。
- 每帧值有限、绝对值 ≤1e7。
- 插值枚举已定义；cubic-bezier 控制点存在且四值均在 `[0,1]`；非 cubic-bezier 不得带控制点。

`ValidateValues(activeTracks)` 用目标 `FloatPropValue.ValidateValue` 检查每个关键帧值。`Validate(config, index)` 合并结构校验与 Active 值校验；Dormant 不产生错误。播放前阻断条件：结构/值问题非空、Active 数量为 0、时长为 0。

### 6.5 运行时状态机

`SimulationRuntime` 持有索引、配置、解析结果、问题、时长、当前时间、播放起点与基础值快照。

| 当前状态 | 操作 | 结果 |
| --- | --- | --- |
| Ready | `TryEnterPreview(t)` | 捕获基础值；`t` 夹取；状态 Preview；应用 `t` |
| Ready/Finished/`t>=T` | `TryPlay` | 当前时间归 0；捕获基础值；状态 Playing；记录播放起点 |
| Preview/Paused/Playing | `TryPlay` | Playing；从当前 `t` 继续（Playing 重复调用直接成功） |
| Playing | `Advance(now)` | `t = playStartTime + max(0, now - playStartedAt)`；Loop 取模；非 Loop 到 `T` 进 Finished；应用 `t` |
| Playing | `Pause(now)` | 先 Advance；仍在 Playing 则转 Paused |
| Playing | `TrySeek/TryStep` | 拒绝并返回错误（UI 会先自动暂停） |
| Ready | `TrySeek(t)` | 等价于进入 Preview；非 Loop 且 `t>=T` 转 Finished |
| 非 Playing | `TryStep(delta)` | `TrySeek(current + delta)`；±1/60 由 UI 传入 |
| 非 Ready | `Stop` | 恢复全部基础值；清会话；Ready；时间 0；配置不变 |
| 非 Playing | `TryUpdateConfig(config)` | 重新解析/校验；成功则更新配置、时长；无会话回 Ready；无 Active 或 `T=0` 自动 Stop；否则夹取当前时间并按 `t` 重算；Finished 但 `t<T` 转 Paused |

基础值策略：首次进入会话时捕获**全部** Float 属性值；每次应用先恢复全部基础值，再写入 Active 轨道的求值结果；停止/离开时只恢复基础值。运行时写入不触发文档通知或历史。`CreateReadout` 生成状态、当前时间、时长、Loop 与所有 Active 轨道的当前值字典。

### 6.6 配置存储

`SimulationConfigStore` 持有当前 `SimulationConfig` 与独立的轨道撤销/重做栈（上限 50）。

| 方法 | 规则 |
| --- | --- |
| `TryAddTrack(id, property, time, value)` | 目标存在且为 Float；同键无轨道；时间/值合法；在 `t` 与 `min(t+1, 3600)` 各放同值线性帧；若两点过近则第二点回退到 `max(0, t-1)` 并保持升序；校验后提交。 |
| `TrySetKeyframeValue(id, property, time, value)` | 同刻（容差 0.0005s）更新值，否则按时间插入；校验后提交。 |
| `TryUpdateKeyframe(index, time, value, interp, bezier)` | 索引存在；时间/值/插值/贝塞尔合法；替换后整体校验。 |
| `TryRemoveKeyframe(index)` | 删除后为空则删除整条轨道；否则校验并提交。 |
| `TryRemoveTrack(id, property)` | 删除整条轨道。 |
| `RemoveDormantTracks()` | 删除全部 Dormant，返回数量；一次撤销条目。 |
| `SetLoop(bool)` | 只更新 Loop，不进撤销栈。 |
| `ExportActive()` | 只保留 Active，按文档图元顺序、再按属性声明顺序排序。 |
| `ReplaceConfig(config)` | 整体替换并清空两个栈（加载文档）。 |
| `CaptureState/RestoreState` | 供导入回滚；恢复配置、Loop 与两个栈。 |
| `ClearHistory()` | 进入仿真页时清空两个栈，保留配置。 |
| `Undo/Redo` | 恢复轨道列表；Loop 保持在当前配置；重做入栈时裁剪到 50。 |

每次候选配置都必须先通过 `SimulationValidator.Validate`；失败不改变配置。

### 6.7 动画范围估算

`SimulationBoundsEstimator.Estimate(roots, config)`：

1. 计算根图元基础包围盒；文档为空返回 null。
2. 解析/校验配置；无 Active 或有问题时返回基础包围盒。
3. 时长 ≤0 返回基础包围盒。
4. 采样时间 = 所有关键帧时间与 `0`、`T` 的排序集合，再插入相邻中点；超过 512 个采样时按关键时间等距降采样，首尾强制为 `0/T`。
5. 逐个采样：恢复全部 Float 基础值 → 写入 Active 求值 → 合并根包围盒。
6. `finally` 恢复基础值；不触发通知或历史。

## 7. 文档格式 v2

### 7.1 JSON 结构

```json
{
  "Version": 2,
  "Primitives": [
    {
      "Id": "00000000-0000-0000-0000-000000000001",
      "Type": "Rectangle",
      "Props": {
        "Name": "Box",
        "PosX": 10,
        "PosY": 10,
        "Width": 20,
        "Height": 20,
        "Color": 4294967295
      }
    },
    {
      "Id": "00000000-0000-0000-0000-000000000002",
      "Type": "Container",
      "Kind": "Rotation",
      "Props": {
        "Name": "Spin",
        "Rotation": 45,
        "Scale X": 1,
        "Scale Y": 1,
        "Offset X": 0,
        "Offset Y": 0
      },
      "Children": []
    }
  ],
  "SelectionIds": ["00000000-0000-0000-0000-000000000001"],
  "Simulation": {
    "Loop": false,
    "Tracks": [
      {
        "PrimitiveId": "00000000-0000-0000-0000-000000000001",
        "Property": "PosX",
        "Keyframes": [
          { "Time": 0, "Value": 10, "Interpolation": "linear" },
          { "Time": 1, "Value": 100, "Interpolation": "cubic-bezier", "Bezier": [0.42, 0, 0.58, 1] }
        ]
      }
    ]
  }
}
```

- 属性键使用模型中的属性名（含 `"Scale X"` 等带空格名称）；`Props` 只写有装箱值的属性。
- 容器额外包含 `Kind`（`Offset`/`Rotation`/`Flip`）与 `Children`；叶子图元不得有非空 `Children`。
- `Simulation` 为可选；省略或 `null` 表示无配置。轨道 `Property` 为 Float 属性名；关键帧 `Interpolation` 取 `linear`、`ease-in`、`ease-out`、`ease-in-out`、`step`、`cubic-bezier`；`Bezier` 仅 cubic-bezier 使用，四项 `[x1,y1,x2,y2]`。
- 序列化使用 `WriteIndented`，属性名大小写不敏感读取。

### 7.2 读取校验

| 检查 | 规则 |
| --- | --- |
| 文本 | 空白或 UTF-8 字节数 >4 MiB 拒绝 |
| JSON | 解析失败、根为空拒绝；解析深度上限 256（领域深度另限 64） |
| 版本 | 非 2 拒绝；通过 `rejectedVersion` 报告缺失版本（0）、1 或未来版本 |
| 图元列表 | 为 null 拒绝；数组元素不得为 null |
| 节点 | 递归深度 >64 或节点数 >10000 拒绝 |
| Id | 空 Guid 拒绝；重复 Id 拒绝 |
| 类型 | 未知 `Type` 拒绝；未知容器 `Kind` 拒绝 |
| 属性 | 未知属性被忽略；已知属性按名称写入；写入后执行领域校验，任一非法拒绝整份文档 |
| 子项 | 仅容器可带子项；叶子带子项拒绝 |
| 选区 | 空 Guid 过滤、去重；未知 Id 在解析后忽略 |
| 仿真段 | 见 7.3 |
| 警告 | 每条警告截断到 240 字符 |

### 7.3 仿真段容错

加载顺序：

1. `Simulation` 缺失/null → 返回 null 配置。
2. 反序列化失败 → 警告“配置被忽略”，返回 null。
3. 轨道数 >2000 → 警告并丢弃整段。
4. 任一道轨为 null / 缺属性名 → 警告并丢弃整段。
5. 原始关键帧总数 >10000 → 警告并丢弃整段。
6. 建立当前文档索引；目标图元不存在或属性不是 Float 的轨道计为 Dormant，**先剪除**。
7. 其余轨道逐条构造（关键帧不得为空、元素不得为 null、插值必须存在、Bezier 必须 4 项）；构造异常 → 警告并丢弃整段。
8. 结构校验失败 → 警告并丢弃整段。
9. Active 值校验失败 → 警告并丢弃整段。
10. 有 Dormant 时追加“已移除 N 条失效轨道”的警告；返回配置。

因此：Dormant 不阻塞加载，Active 结构性非法时整段配置丢弃，但文档本身仍加载。

### 7.4 存储与文件边界

| 边界 | 规则 |
| --- | --- |
| localStorage 键 | `penelopa.document`；备份 `penelopa.document.backup` |
| Save | 序列化 → 读旧值 → 旧值非空则先写 backup → 写主键 → 触发 `Saved` |
| 备份失败 | 终止保存并返回错误；主键不被覆盖 |
| Load | 读主键 → 空/缺失提示；反序列化失败按版本给原因；成功返回结果，确认后应用 |
| 文件扩展名 | 必须为 `.json`（大小写不敏感）；提示文案接受 `.penelopa.json` 或 `.json` |
| 文件大小 | >4 MiB 拒绝 |
| 文件编码 | `UTF8Encoding(throwOnInvalidBytes: true)`；接受 BOM 并去除；拒绝 UTF-16/32 与非法字节 |
| Import | 只解析与替换内存，不写 localStorage；确认前不改变文档 |
| Export | 使用当前内存文档、选区与 `ExportActive`；文件名 `penelopa-yyyyMMdd-HHmmss.penelopa.json`；Blob 下载 |
| 示例 | `samples/loop-study-01.penelopa.json`，与用户文件同一解析路径 |
| 导入应用 | `ReplaceAll`（清空文档历史）→ 设置选区 → `ReplaceConfig`（清空配置历史） |
| 导入回滚 | 捕获文档历史状态、选区、配置状态；替换失败恢复；成功后快照保留；Structure/Geometry 变化、配置变化、`Saved`、再次替换均使其失效 |

### 8.3 编辑页行为

- Tools：添加三种叶子图元；若恰好单选一个容器则加入容器；添加三种容器并选中。

- 文档操作互斥：`_isSaving/_isLoading/_isImporting/_isExporting` 期间相关按钮禁用；导入控件同时置 `aria-disabled`。
- Align：直接调用服务；Group/Ungroup 根据选区状态启用；错误显示在面板。
- 属性面板：`FindCommonProperties` 取所有目标同名同类型属性；`PropEditorBase` 计算冲突、生成稳定字段 id、错误 id；冲突占位不提交空值；提交走 `TrySetProperty` 批量原子写入。
- 树：Astrea `Tree` 渲染完整层级；普通点击单选，Ctrl/Meta 追加或切换，选区与画布/属性面板共享并遵循 ED-F-015；选中状态使用 `aria-selected`，树内 Delete 与 Ctrl+Z/Y 通过 `OnKeyDown` 转发到文档服务。
- 画布：`CanvasPanel` 持有 `CanvasRenderer` 与控制器；订阅 `PrimitiveService.Changed`；首帧加载 DPR 监听与指针层；按需 `Invalidate`；样例加载有取消令牌与“画布已变化”检查；卸载先解绑 JS 再释放 .NET 引用。
- 键盘：TS 全局监听；输入控件内直接返回；Esc/Delete 全局；方向键仅在画布本身聚焦时；Ctrl+Z/Y 全局（输入控件除外）。
- 指针：仅主鼠标键或主触摸；指针捕获；rAF 节流 move；`touch-action: none` 由拖动类控制；`ResizeObserver`/滚动/尺寸变化使坐标原点失效。

### 8.4 仿真页行为

- 初始化：重建 Atlas 工作区；读取共享文档；构建索引；清空配置历史；若编辑器单选项仍存在则作为初始选中；创建运行时并估算 Fit 范围。
- 选中项：仿真页独立 `_selectedId`，不回写编辑器选区；切换图元清空轨道/关键帧选择。
- 仿真树：与编辑树共用 `Astrea.Components` 0.8.0 的 `Tree` 和 `PrimitiveTreeSnapshot` 映射（`net6.0`，MIT）。每个 `Primitive` 映射为稳定 `TreeNode`（`Id = GuidN`、`BindData = Primitive`），容器递归挂接并默认展开；仿真树受控单选回写 `_selectedId`，`IconTemplate` 提供类型图标，`NodeTemplate` 提供名称与动画徽标；树行样式通过 `--ast-tree-*` 映射 `--penelopa-*` 令牌。`OperatingSystem.IsBrowser()` 控制内置键盘导航，bUnit 渲染时关闭以避免 JS 互操作。Astrea 会停止树内 keydown 冒泡，因此页面级 Ctrl+Z/Y 通过 `Tree.OnKeyDown` 转发到配置撤销/重做。
- 传输条：主按钮文案按状态 Play/Resume/Pause/Replay；Stop、±1/60、Loop（`aria-pressed`）、Undo/Redo、状态文本（`aria-live="polite"`）与时间读数。
- 播放：`TryPlay(NowSeconds)` → 启动 JS rAF 循环；帧回调 `Advance` → 重绘 → 20Hz 发布读数；Finished 停止循环；标签页隐藏自动 Pause；运行时异常结束会话并显示错误。
- 定位/步进：Playing 时先自动暂停再执行；失败显示阻断问题。
- 配置编辑：Playing 时 `CanEditConfig=false`；轨道/关键帧操作通过 `SimulationConfigStore`；配置变化后刷新 Dormant、校正选择、更新运行时；Ready 时重新估算 Fit 范围。
- 关键帧选择校正：优先同索引同时间；否则按时间重定位；撤销导致索引漂移时保持同一帧；失败清空选择。
- Save：仅 Ready；有 Dormant 先显示确认；成功/失败消息在页内显示。
- 离开：`Back`、浏览器后退、路由变化、组件销毁都调用 `EndSession` 恢复基础值；若曾建立会话，用 `Transient` 通知编辑页刷新，不使导入回滚失效；`DisposeAsync` 在任何 `await` 前同步恢复。
- 时间轴：只显示当前选中图元的轨道；刻度数量/间隔随缩放自适应；通过滚动容器横向滚动；播放头与刻度 seek；关键帧单击选择、双击 Go to、拖动重定时（3px 阈值、1/60 吸附、相邻 1ms 间隔、Esc 取消）。
- 检视器：Float 属性列表带当前值；未绑定显示 Animate；已绑定显示关键帧表；Add keyframe 在播放头处取当前值，同刻更新；编辑时间/值/插值/贝塞尔；Go to；删除最后一帧即删除轨道。
- Dormant：页面顶部显示数量、“Remove inactive”、可展开明细（短 Id、属性、关键帧数、逐条 Remove）；清理走配置撤销。
- 焦点：`FocusOnNavigate` 选择 `h1, [data-testid='penelopa-simulate-link']`；进入仿真页聚焦 h1，返回编辑页聚焦 Simulate 链接。
- 错误：运行时错误、保存失败、Dormant 保存确认、校验阻断、空状态均有独立可见区域。

### 8.5 导入回滚生命周期

| 事件 | 行为 |
| --- | --- |
| 导入确认 | 捕获文档历史状态、选区、配置状态；挂起自身事件；应用替换；成功替换快照 |
| 应用失败 | 恢复捕获状态，保留旧快照（若有），返回错误 |
| 文档 Structure/Geometry 变化 | 丢弃快照 |
| 仿真配置变化（含 Loop） | 丢弃快照 |
| 成功保存（`DocumentStorage.Saved`） | 丢弃快照 |
| 选区、视图、Export、播放 | 不影响快照 |
| 再次导入/Load/刷新 | 新快照替换旧快照；Load 触发 Structure 清空；刷新自然丢失 |
| 撤销导入 | 恢复文档历史（含两个栈）、选区、配置（含 Loop 与两个栈）；不产生历史条目，无可重做 |

## 9. 错误处理与边界

| 场景 | 处理 |
| --- | --- |
| 文档 JSON 无效/版本不支持 | Load/Import 返回带原因的结果；当前文档不变；不删除旧 localStorage |
| 仿真段非法 | 保留文档，丢弃配置，警告显示在加载/导入消息中 |
| localStorage 读写异常 | JS 返回结果对象；.NET 转单行摘要；保存失败不提示成功 |
| 文件读取异常 | 扩展名/大小/编码前置拒绝；流/互操作异常显示“无法读取” |
| 导入应用失败 | 回滚到导入前快照；错误可见 |
| 属性非法 | 字段就地错误；不写入；多选原子回滚 |
| 事务取消/手势取消 | 快照精确恢复；通知一次 |
| 仿真校验失败 | 阻止播放/预览；汇总全部阻断原因；状态不变 |
| 仿真运行期异常 | 结束会话、恢复基础值、显示错误 |
| JS 互操作不可用 | 增强功能降级（焦点、拖放、性能钩子），核心按钮仍可用 |
| 画布/颜色键容量 | 超过颜色键容量抛可诊断异常；文档上限在加载阶段拒绝 |

## 11. 扩展点

### 11.1 新增图元类型

1. 继承 `Primitive`，在构造函数注册属性并实现局部包围盒、平移、`SetBoundsLocal`、命中测试。
2. 在 `ScenePainter.DrawNode` 增加可见与命中绘制；在 `DocumentSerializer.FromDto` 增加类型映射。
3. 在 `ToolPanel` 增加创建按钮；补充 Core 几何/序列化测试与渲染/命中测试。
4. 若含 Float 属性，仿真索引与检视器会自动识别；若新增属性子类型，必须在 `PropValue.GetBoxedValue/SetBoxedValue` 注册转换。

### 11.2 新增插值

1. 扩展 `InterpolationKind` 与 `SimulationEvaluator.Ease`。
2. 在 `DocumentSerializer` 的字符串映射与会话校验中登记。
3. 在 `SimulationKeyframeEditor` 提供选项；补充求值、序列化与校验测试。

### 11.3 主题与布局

- 视觉语言采用中性工具工作区：亮/暗双主题、1px 分隔线、4px 圆角，强调色只用于品牌标记、选区导轨、焦点与唯一主操作。`app.css` 与 `simulation.css` 共享同一套 `--penelopa-*` 语义令牌（背景、表面、文本层级、分隔线、选中态、反馈色、滚动条、舞台与浮层阴影）；Atlas 外壳通过 `--atlas-*` 覆盖保持一致。
- 面板头部与工具标签使用 10–11px 大写字母与字距；数据值、名称与时间读数使用等宽字体。顶栏高 46px，状态栏高 26px，面板头部高 34px。
- 工作区节点通过 `PenelopaWorkspaceDefinition` / `SimulationWorkspaceDefinition` 声明；改布局需保持仿真四个必需区域可访问，并同步布局集成测试。文档组承载 GPU 画布，保持直角边缘以免圆角裁剪导致画布角落合成抖动；工具组保留 4px 圆角。
- 窄视口下侧栏压缩、按钮单列化、颜色通道换行，但不得出现横向溢出；所有新控件复用现有令牌与焦点样式。
- 编辑树与仿真树共用 Astrea Tree 的 WAI-ARIA 结构（`role="tree"/"treeitem"`、`aria-selected`、单 Tab 停靠 + 方向键）；样式通过 `.penelopa-tree-view` 作用域覆盖，保持 26px 行高、全行选中导轨与右侧动画点，暗色模式由令牌自动适配。

## 12. 测试钩子与可观测性

- `InternalsVisibleTo`：`Penelopa.Rendering.Tests` 可访问内部渲染类型，`Penelopa.Web.Tests` 可访问 Web 内部类型。
- `HitTestBuffer` 提供内部构造函数指定起始颜色键，用于容量边界测试。
