## 1. 目的与范围

### 1.1 目的

本文档定义 Penelopa 编辑器和仿真页面的功能需求、非功能需求、验收标准与限制，作为设计、测试与交付验收的共同依据。

### 1.2 基线声明

本文档是**实现基线反向基线化**的结果：项目先完成实现，再以提交 `48cdf6d` 的行为为准整理需求，因此需求描述的是当前系统应保持的行为，而不是前期客户原始需求或变更过程的记录。仿真部分沿用既有的 `SIM-F-*`、`SIM-NF-*` 编号，编辑器部分新增 `ED-F-*`、`ED-NF-*` 编号，便于现有测试与代码注释继续追溯。

### 1.3 范围

产品包含两个页面：

- 编辑页 `/`：图元创建、选择、编辑、对齐、分组、撤销/重做、文档持久化与文件导入导出。
- 仿真页 `/simulation`：为图元 Float 属性编排关键帧、播放预览、编辑仿真配置，并把配置随文档保存。

不包含服务器端、多人协作、运行时动画引擎与移动端专项适配，详见第 7 节。

## 2. 术语

| 术语 | 定义 |
| --- | --- |
| Primitive（图元） | 文档中的可编辑对象，包含名称、属性和可选的父容器。 |
| Container（容器） | 对子图元施加平移、旋转或翻转变换的图元，本身无可见形状。 |
| Root（根图元） | 没有父容器的图元；文档由有序根列表构成。 |
| Widget | 仿真语境下的图元，包括容器。 |
| Track（轨道） | 一个 `(图元, Float 属性)` 的动画通道，每对最多一条。 |
| Keyframe（关键帧） | 轨道上的 `(时间, 值, 插值方式)`。 |
| Timeline（时间轴） | 全局绝对时间区间 `0..T`。 |
| Playhead（播放头） | 当前时间 `t`。 |
| Base value（基础值） | 文档中未被仿真临时改写的属性值。 |
| Session（检查会话） | 从首次播放、定位或步进开始，到停止或离开页面结束。 |
| Active track | 目标图元存在且属性仍为 Float 的轨道。 |
| Dormant track | 目标图元已删除、保留但不参与求值的轨道。 |
| Preview | 从 Ready 通过定位或步进进入的暂停会话。 |
| Finished | 非循环播放到达 `T` 后保持末帧的状态。 |
| AABB | 轴对齐包围盒。 |

## 3. 产品概述

### 3.1 用户与场景

Penelopa 面向需要快速搭建二维图元布局并验证属性动画的设计与开发人员。典型场景是：在编辑页创建图形、调整层级与属性、对齐和分组；随后进入仿真页，把位置、尺寸、旋转或缩放编排为关键帧，检查运动效果；最后把文档与动画配置保存为本地文件或浏览器存储。

### 3.2 运行环境

- 纯浏览器 WebAssembly 应用，无后端接口；部署于静态站点（GitHub Pages）。
- 主验收视口为 1440×900 与 1024×768。
- 文档保存在浏览器 localStorage，或通过 `.penelopa.json` 文件在本地交换。
- 支持 WebAssembly 与 WebGL 的现代桌面浏览器；自动化验收环境为 Chromium。

### 3.3 主要能力

| 能力 | 说明 |
| --- | --- |
| 图元编辑 | 圆形、矩形、三角形；偏移、旋转、翻转容器；层级与钻取选择 |
| 属性编辑 | 强类型属性、领域校验、多选原子编辑、名称重命名 |
| 布局工具 | 六方向对齐、分组与取消分组 |
| 视图与手势 | 拖拽移动、角柄缩放、平移、Ctrl+滚轮缩放、Fit、DPI 一致 |
| 历史 | 按事务撤销/重做，手势取消精确恢复 |
| 持久化 | localStorage Save/Load（v2）、单槽备份、手动加载 |
| 文件 I/O | v2 JSON 导入/导出、拖放导入、一次性导入回滚、内置样例 |
| 仿真 | 关键帧轨道、六种插值、播放状态机、全局循环、Dormant 清理、配置撤销 |
| 可访问性 | 键盘路径、ARIA、焦点管理、状态播报、减少动态效果提示 |

## 4. 功能需求

### 4.1 编辑器

#### 4.1.1 文档模型与图元

- **ED-F-001** 文档必须由有序的根图元列表构成；每个图元必须具有稳定且唯一的 GUID `Id`，以及不可为空的名称属性。
- **ED-F-002** 系统必须提供 `Circle`、`Rectangle`、`Triangle` 三种叶子图元；圆由中心与半径定义，矩形由左上位置与宽高定义，三角形由三个顶点定义。
- **ED-F-003** 系统必须提供 `Container`，其编辑形态为 Offset（偏移）、Rotation（旋转）、Flip（翻转）；形态决定属性面板暴露的变换属性。
- **ED-F-004** 图元属性必须强类型存储并支持文本提交校验；数值属性拒绝 NaN、无穷与绝对值超过 `1e7` 的值；`Radius`、`Width`、`Height` 必须大于 0；颜色文本必须接受 `#RRGGBB` 或 `#RRGGBBAA` 并规范化为 ARGB。
- **ED-F-005** 容器必须按 `平移 · 旋转 · 缩放` 组合对子图元施加仿射变换；生效缩放幅值必须钳位到不小于 `0.01`，避免不可逆变换，属性面板保留用户输入值。
- **ED-F-006** 图元的世界包围盒必须由自身局部包围盒沿父容器链逐级变换得到；容器的局部包围盒必须为其子项包围盒的并集经本容器变换后的 AABB。
- **ED-F-007** 根列表顺序即渲染 Z 序，后绘制的图元覆盖先绘制的图元；容器子项按容器内顺序绘制。
- **ED-F-008** 图元名称必须非空、去除首尾空白、长度不超过 128 字符；重命名必须可撤销。
- **ED-F-009** 图元只能有一个父级；跨文档挂载、循环挂载、空 Id、重复 Id 与非法属性必须在结构变更或加载时被拒绝。

#### 4.1.2 创建与选择

- **ED-F-010** Tools 面板必须提供添加 Circle、Rectangle、Triangle 的按钮；新图元使用模型默认属性值。
- **ED-F-011** 添加叶子图元时，若当前恰好选中一个容器，则新图元必须加入该容器；否则必须加入根列表。
- **ED-F-012** Tools 面板必须提供 Offset、Rotate、Flip 三种容器创建按钮；创建后必须选中新容器。
- **ED-F-013** 画布单击必须选择命中图元；带 Ctrl 或 Meta 的单击必须追加或切换该图元；单击空白必须清空选择。
- **ED-F-014** 嵌套图元的首次点击必须选择最外层可命中的容器；同一位置 500ms 内、4 世界单位容差内的连续点击必须逐层钻取到最深叶子。
- **ED-F-015** 选区必须在所有入口规范化：若祖先已选中，则其后代不得同时出现在选区中。
- **ED-F-016** 多选时点击已选成员：单击（未拖动）必须把选择折叠为该项目；拖拽必须移动整个选区一次。
- **ED-F-017** 图元树必须展示完整层级（含容器后代）并暴露 WAI-ARIA 树语义（`role="tree"`/`role="treeitem"`、`aria-selected`）；单击节点必须只选中该图元，带 Ctrl 或 Meta 的点击必须追加或切换选中，选中状态必须与画布及属性面板一致并遵循 ED-F-015 规范化。
- **ED-F-018** 单选时属性面板必须显示全部属性；多选时只显示所有目标都具备的同名同类型公共属性。
- **ED-F-019** 多选属性编辑必须在值一致时显示共享值，在不一致时显示 `Multiple values` 占位；提交必须原子写入所有目标，任一目标失败时回滚全部写入，成功时只产生一个撤销条目。

#### 4.1.3 画布手势与视图

- **ED-F-020** 指针按下后，移动超过 3 世界单位才必须开始拖拽；拖拽必须按世界坐标增量移动当前顶层选区。
- **ED-F-021** 单选且可缩放时，必须提供四角缩放手柄；缩放必须固定对角，最小尺寸为 1×1 世界单位，拖过固定角必须允许镜像。
- **ED-F-022** 图元自身或祖先容器含旋转/剪切时，必须禁用角柄并禁止世界轴缩放。
- **ED-F-023** 在空白处按下必须清空选择；继续拖动必须按 CSS 像素增量平移视口。
- **ED-F-024** Ctrl+滚轮必须以指针下的世界点为中心缩放，缩放范围必须为 `0.05..8`；普通滚轮必须留给页面滚动。
- **ED-F-025** Fit 按钮必须把全部根图元的包围盒适配到视口，保留 40 CSS 像素内边距，缩放夹取到 `0.05..4`。
- **ED-F-026** 画布必须以物理像素渲染，渲染与命中测试必须共享同一视口变换；设备像素比变化时必须更新分辨率并保留用户的缩放与平移。
- **ED-F-027** 画布必须位于可滚动容器中；面板尺寸变化不得重置缩放/平移。
- **ED-F-028** 指针交互必须使用指针捕获；`pointercancel`、失去捕获、窗口失焦或页面隐藏时必须取消当前手势并精确恢复。
- **ED-F-029** 编辑页画布必须绘制坐标轴，坐标轴必须位于内容下方且不参与命中测试。

#### 4.1.4 键盘与历史

- **ED-F-030** 画布本身获得焦点时，方向键必须按 1 世界单位移动选区，Shift+方向键按 10 世界单位移动；焦点位于输入框、文本域、下拉框或可编辑区域时不得劫持按键。
- **ED-F-031** Delete 必须删除当前选区；焦点位于文本控件内时 Delete 必须只作用于文本。
- **ED-F-032** Ctrl+Z 必须撤销，Ctrl+Y 或 Ctrl+Shift+Z 必须重做；焦点位于文本控件内时必须交还浏览器原生撤销。
- **ED-F-033** Escape 必须取消当前拖拽或缩放手势，并精确恢复到手势前状态。
- **ED-F-034** 所有文档修改必须通过事务边界：结构变更、对齐、属性编辑、键盘移动与画布手势必须各自产生一个撤销条目；无实际变化时不得产生条目。
- **ED-F-035** 撤销/重做不得捕获或恢复选区；恢复后只保留仍存活的选中项。
- **ED-F-036** 历史快照必须包含根列表顺序、每个图元的属性值与容器子元素顺序，不包含选区和仿真配置。
- **ED-F-037** 拖拽/缩放必须在首次实际修改前开启事务；提交或取消时只通知一次几何变更。
- **ED-F-038** 对齐操作必须可撤销；选区已对齐时不得移动或产生历史条目。
- **ED-F-039** 删除图元、替换文档或恢复快照后，选区中已不在文档内的图元必须被清理。

#### 4.1.5 对齐与分组

- **ED-F-040** 系统必须提供左、水平居中、右、上、垂直居中、下六种对齐；参考值必须为选中项世界包围盒的并集。
- **ED-F-041** 对齐只能平移图元，不得改变尺寸或旋转；少于两个选中项时不得操作；全部已对齐时必须返回未变更且不产生历史。
- **ED-F-042** 对齐必须遵循画布 y 翻转语义：视觉顶部对应世界 `MaxY`，视觉底部对应世界 `MinY`。
- **ED-F-043** 分组必须要求至少两个根级选中项；必须创建 identity（零偏移、零旋转、单位缩放）的 Offset 容器，插入到第一个选中根的位置，子项按根顺序进入容器，世界位置与 Z 序保持不变，结构与选区必须在同一事务中提交。
- **ED-F-044** 分组成功后必须只选中新容器。
- **ED-F-045** 取消分组必须要求单选根级 identity 容器；子项必须按原顺序放回根列表并全部选中；嵌套容器或非 identity 容器必须被拒绝且不产生历史。
- **ED-F-046** 条件不满足时 Group/Ungroup 按钮必须禁用；服务层拒绝时必须在面板中显示可见原因。

#### 4.1.6 持久化

- **ED-F-050** Save 必须把当前根图元、选区 Id 与 active 仿真配置序列化为 v2 文档，写入 localStorage 键 `penelopa.document`。
- **ED-F-051** Save 必须先把 `penelopa.document` 中已有的非空负载写入单槽备份 `penelopa.document.backup`；备份写入失败时必须终止保存并报错。
- **ED-F-052** Load 必须读取 localStorage，解析成功后先显示确认；确认后必须整体替换文档、选区与仿真配置。
- **ED-F-053** localStorage 读/写失败（配额、隐私模式、安全限制、JS 异常）必须转换为可见的单行错误，不得提示成功，不得把堆栈回显给用户。
- **ED-F-054** 系统必须只接受版本 2 文档；缺失版本、版本 1 与高于 2 的版本必须被 Load、Import 和样例加载拒绝，并给出对应原因；拒绝时不得删除或改写旧数据。
- **ED-F-055** 文档必须限制为 4 MiB、10000 个图元、容器嵌套深度 64；Id 必须唯一且非空；属性值必须通过领域校验，否则整份文档拒绝。
- **ED-F-056** 文档 JSON 必须包含 `Version`、`Primitives`、`SelectionIds`，可选 `Simulation`；容器必须包含 `Kind` 与 `Children`，属性必须按名称存储。
- **ED-F-057** 加载后必须按 Id 解析选区，未知 Id 必须忽略；空选区必须显式应用，不能保留旧选区。
- **ED-F-058** 加载时若 `simulation` 段非法，必须保留文档、丢弃整段仿真配置并显示警告；目标已不存在的轨道必须剪除并计入警告。
- **ED-F-059** 应用不得自动保存或自动加载；刷新后必须由用户显式 Load。

#### 4.1.7 文件 I/O 与样例

- **ED-F-060** Import file 必须只接受单个 `.json` 文件；扩展名不符、文件大于 4 MiB、UTF-16/UTF-32 或非法 UTF-8 字节序列必须拒绝；UTF-8 BOM 必须接受。
- **ED-F-061** Import 必须先解析并完整校验，再显示图元总数、active 轨道数与警告，用户确认后才替换文档；导入不得写入 localStorage。
- **ED-F-062** 导入确认期间，若文档内容或仿真配置发生变化，必须取消待确认的导入并提示重新选择。
- **ED-F-063** 导入成功后必须提供一次性 `Undo import`，恢复导入前的文档、选区、文档撤销/重做栈、仿真配置与 Loop；持久编辑、配置变更、成功保存、再次导入/Load 或刷新后必须失效。
- **ED-F-064** Export file 必须生成与 Save 相同的负载，文件名必须包含时间戳并以 `.penelopa.json` 结尾，通过浏览器下载；导出不得写入 localStorage，空文档也必须可导出。
- **ED-F-065** Save 与 Export 必须排除 Dormant 轨道；存在 Dormant 轨道时必须要求用户确认排除，取消时不得执行。
- **ED-F-066** 把 `.penelopa.json` 拖放到编辑页任意位置必须触发与 Import 按钮相同的流程；拖放必须显示遮罩，必要时自动激活 Tools，操作进行中必须拒绝并显示可见提示。
- **ED-F-067** 隐藏的文件输入必须在每次读取完成后复位，使同一文件可以被再次选择。
- **ED-F-068** 空编辑器必须提供内置 `Loop Study 01` 示例；加载后必须选中 `Step Indicator` 且不得自动播放；加载期间画布发生结构或几何变化时，样例请求必须取消并显示提示。
- **ED-F-069** 内置示例必须与用户文件走同一套 v2 解析与领域校验。

#### 4.1.8 工作区与界面反馈

- **ED-F-070** 编辑页必须使用六区域可停靠工作区：Tools、Primitives、Document 画布、Properties，以及四个空工具组（左右停靠区下部与底部两侧）；侧栏必须使用比例布局并允许调整、折叠和移动。
- **ED-F-071** 在 700–1440 CSS 像素视口范围内，画布必须保持可用宽度；默认比例轨道不得因固定像素侧栏而被完全挤压。
- **ED-F-072** 所有交互控件必须使用原生按钮、输入框或下拉框，并提供可见文本或可访问名称；输入框必须有标签，错误必须通过 `aria-describedby` 关联。
- **ED-F-073** 编辑画布必须以 `role="application"` 暴露并关联键盘帮助文本；仿真画布必须以只读图像语义暴露。
- **ED-F-074** 状态、错误与警告必须使用 `role="status"`、`role="alert"` 或 `aria-live` 播报；高频时间/数值读数不得实时播报。
- **ED-F-075** 无图元、无选中项、无轨道、无活动轨道、无 Dormant 明细等状态必须提供明确的空状态或禁用原因。
- **ED-F-076** 路由切换必须更新页面标题；进入仿真页时焦点必须落在页面标题，返回编辑页时焦点必须回到 Simulate 入口。
- **ED-F-077** 仿真页的只读画布不得绘制坐标轴、不得重建命中缓冲、不得提供选择或手柄。
- **ED-F-078** 文档操作（Save、Load、Import、Export）进行中必须禁用其他文档操作按钮，避免并发替换或覆盖。

### 4.2 仿真

#### 4.2.1 对象与会话边界

- **SIM-F-001** 仿真的作用对象必须是现有图元（含容器），不得引入新的运行时控件类型或平行渲染模型。
- **SIM-F-002** 仿真页必须是几何只读的：不得新增、删除、重命名、对齐、分组、取消分组、拖拽、缩放或通过画布改变图元结构。
- **SIM-F-003** 仿真必须是预览行为：播放、暂停、定位期间临时写入的属性值不得进入文档模型、撤销历史或保存结果；停止、离开页面或组件销毁时必须精确恢复基础值。
- **SIM-F-004** 仿真配置必须独立于 `Primitive.Props`，按 `Primitive.Id` 与 Float 属性名关联；不得通过新增图元属性来表达动画。
- **SIM-F-005** 编辑器的文档撤销/重做不得修改仿真配置；删除图元只允许让对应轨道变为 Dormant，撤销删除后必须自动恢复为 Active。

#### 4.2.2 页面与导航

- **SIM-F-010** 编辑页顶栏必须提供进入 `/simulation` 的入口；仿真页顶栏必须提供返回编辑页的入口。
- **SIM-F-011** 仿真页必须共享当前内存中的同一份文档；不得创建独立文档或产生副本。直接访问 `/simulation` 时若文档为空，必须显示空状态而不是报错。
- **SIM-F-012** 仿真页顶部传输条必须包含：Back to editor、Save、Play/Pause/Replay、Stop、Loop 开关、当前时间读数、`-1/60s` 与 `+1/60s` 步进。
- **SIM-F-013** 仿真页必须提供：顶部传输条、左侧只读图元树、中间只读画布、右侧检视器、底部通栏时间轴。默认布局必须同时呈现这些区域；图元树、检视器和时间轴不可关闭或自动隐藏，但可在会话内调整大小、折叠、移动和重新分组；画布是只读文档，不可关闭、折叠或分割。
- **SIM-F-013A** 必需区域被折叠或重新分组后必须仍可访问并恢复；每次进入仿真页必须重建默认布局。
- **SIM-F-013B** 播放期间必须允许布局移动、折叠与分割条调整，且不得停止播放、改变当前时间或丢失基础值快照。
- **SIM-F-014** 画布不得提供点选、拖拽、缩放手柄或命中测试交互，并必须以只读图像语义暴露给辅助技术。
- **SIM-F-015** 仿真页必须维护自己的选中项，不得修改编辑页的选区。
- **SIM-F-016** 图元树必须展示完整层级（含容器后代），并对已有轨道的图元显示动画徽标。
- **SIM-F-017** 底部时间轴只允许展示当前选中图元的轨道，不提供全图元轨道总览。
- **SIM-F-018** 无图元、无选中项、无轨道、无活动轨道时必须提供明确的空状态或禁用原因。
- **SIM-F-019** 通过 Back、浏览器后退或任何路由退出离开仿真页时，必须先结束会话并恢复基础值。

#### 4.2.3 轨道与关键帧数据

- **SIM-F-020** 每个 `(图元, Float 属性)` 最多允许一条轨道；不同属性可以并行运动。
- **SIM-F-021** 一条轨道至少包含 1 个关键帧。新建轨道时必须自动放置两个关键帧：播放头处当前显示值、`min(t + 1s, 3600s)` 处同值；若两者时间相同，则第二个放在 `max(0, t - 1s)` 并保持时间升序。
- **SIM-F-022** 关键帧必须包含时间、值和插值方式：
  - 时间单位为秒，必须是有限数，范围 `0..3600`，同一轨道内严格递增且不重复。
  - 值必须是有限数，绝对值不超过 `1e7`，并必须通过对应属性的现有领域约束（如 `Radius > 0`、`Width > 0`）。
  - 插值方式作用于该关键帧到下一关键帧的区间。
- **SIM-F-023** 支持的插值方式必须包括：
  - `linear`
  - `ease-in`、`ease-out`、`ease-in-out`
  - `step`：保持本帧值，到下一关键帧时间点跳变
  - `cubic-bezier(x1, y1, x2, y2)`：四个控制点必须都在 `[0, 1]` 内，不允许 overshoot
- **SIM-F-024** 最后一个关键帧的插值设置不参与求值，UI 必须禁用或隐藏该设置。
- **SIM-F-025** 所有轨道必须共享一条全局绝对时间轴；`T` 必须取所有 Active 轨道最后一个关键帧时间的最大值。全局 Loop 必须取代逐轨循环。
- **SIM-F-026** 关键帧的值必须按**属性原值 / 父空间**解释并写入。UI 必须标注“相对父级”；不得把 From/To 转换成世界坐标，也不得引入第二套坐标真源。
- **SIM-F-027** 上限必须为：轨道 ≤ 2000、单轨关键帧 ≤ 200、文档关键帧总数 ≤ 10000；仍受文档 4 MiB 上限约束。

#### 4.2.4 求值与属性写入

- **SIM-F-030** 对当前时间 `t`，每条 Active 轨道必须按以下规则求值：
  - `t` 小于等于首个关键帧时间：取首帧值。
  - `t` 大于等于末个关键帧时间：取末帧值。
  - 位于两帧之间：`u = (t - t_i) / (t_{i+1} - t_i)`，`e = interpolate(u, k_i.interpolation)`，`value = v_i + (v_{i+1} - v_i) * e`。
  - `step` 在区间内恒为 `v_i`，到 `t_{i+1}` 切换。
- **SIM-F-031** 插值因子必须始终落在 `[0, 1]`；由于端值合法，求值过程中不得产生非法领域值，也不得需要逐帧钳位。
- **SIM-F-032** 每次求值必须在当前时刻为所有 Active 轨道属性写入计算值；未被 Active 轨道覆盖的 Float 属性必须写入基础值。
- **SIM-F-033** 在会话开始时必须捕获文档中所有 Float 属性的基础值；停止、离开页面或异常终止时恢复。删除轨道后，对应属性必须立即恢复基础值。
- **SIM-F-034** 仿真期间的属性写入不得触发文档变更通知、撤销条目或序列化；渲染由仿真帧显式请求重绘。

#### 4.2.5 播放状态

仿真页必须实现以下状态；同一时刻只能处于一种状态。

| 状态 | 画布 | 时钟 | 可编辑配置 | Save | 主按钮 |
| --- | --- | --- | --- | --- | --- |
| Ready | 基础值 | 停 | 是 | 是 | Play |
| Preview | `t` 求值 | 停 | 是 | 否 | Resume |
| Playing | `t` 求值 | 走 | 否 | 否 | Pause |
| Paused | `t` 求值 | 停 | 是 | 否 | Resume |
| Finished | `T` 求值 | 停 | 是 | 否 | Replay |

- **SIM-F-040** 进入页面及停止后必须处于 Ready，并显示基础值；播放头停在 0 不代表已应用动画首帧。
- **SIM-F-041** 从 Ready 拖动播放头、点击刻度或单帧步进必须进入 Preview；首次 Play 也必须建立会话并捕获基础值快照。
- **SIM-F-042** Play 在 Ready 时必须从 0 开始；在 Preview / Paused 时必须从当前 `t` 继续；在 Finished 时必须从 0 重新播放。
- **SIM-F-043** Loop 关闭时，播放到达 `T` 必须进入 Finished 并保持末帧，不得自动回弹或自动停止。Loop 开启时不得进入 Finished，`t` 必须对 `T` 取模循环。
- **SIM-F-044** Stop 在所有非 Ready 状态必须可用；执行后必须结束会话、恢复全部基础值、播放头回到 0、状态回到 Ready，配置保持不变。
- **SIM-F-045** 播放中切换 Loop 开关必须立即生效；在 `t < T` 时关闭 Loop 必须继续播放到 `T` 后进入 Finished。
- **SIM-F-046** 无 Active 轨道或 `T <= 0` 时，Play、定位和步进必须禁用，并说明原因。
- **SIM-F-047** Finished 状态下编辑配置导致 `T` 或关键帧变化时：若仍存在活动轨道且 `t < T`，必须转为 Paused；若没有活动轨道或 `T <= 0`，必须回到 Ready 并恢复基础值。

#### 4.2.6 时间控制与计时器

- **SIM-F-050** 仿真必须使用单一帧时钟，目标 60FPS；每帧必须基于单调时间戳计算经过时间，不得用固定步长累加，以避免漂移。
- **SIM-F-051** 浏览器标签页隐藏时必须自动暂停 Playing 会话；返回页面后必须保持 Paused，由用户显式恢复。
- **SIM-F-052** 当前时间读数必须显示秒并保留 3 位小数；播放期间必须以 20Hz 节流更新轨道当前值；暂停、定位和编辑后必须立即刷新。
- **SIM-F-053** 画布必须以 60FPS 更新，文本读数必须以 20Hz 更新；二者不得互相拖慢，也不得导致整页每帧重渲染。
- **SIM-F-054** 播放头拖动和刻度点击必须支持 seek；范围必须夹取到 `[0, T]`。在 Playing 中 seek 或步进必须先自动暂停。
- **SIM-F-055** 单帧步进必须为 `±1/60s`，夹取到 `[0, T]`；从 Ready 步进必须进入 Preview。
- **SIM-F-056** 时间轴必须默认适配整条时间轴，并提供放大、缩小与横向滚动；刻度间隔必须随缩放自适应。
- **SIM-F-057** 在给定 `t` 下，求值结果必须与帧率无关、可重复；定位、步进和重新播放到同一时刻必须得到相同属性值。

#### 4.2.7 编辑交互与配置撤销

- **SIM-F-060** 右侧检视器必须列出当前选中图元的全部 Float 属性；未绑定项提供 Animate，已绑定项显示轨道、当前值与关键帧编辑入口。
- **SIM-F-061** 点击 Animate 必须按 SIM-F-021 创建轨道，并捕获播放头处该属性的当前显示值。
- **SIM-F-062** Add keyframe 必须在播放头处捕获当前求值结果；若该时刻已有关键帧，必须更新该关键帧而不是新增重复时间。
- **SIM-F-063** 关键帧的时间、值和插值方式必须可在检视器中编辑；自定义贝塞尔必须提供 4 个数值控制点。
- **SIM-F-064** 时间输入必须支持 1ms 精度；与相邻关键帧冲突时必须拒绝并就地报错，不得静默重排。
- **SIM-F-065** 值输入必须沿用属性领域校验；非法值不得写入模型。
- **SIM-F-066** 时间轴上的关键帧必须支持横向拖动重定时，吸附到 `1/60s` 网格，并夹在相邻关键帧之间且保持至少 1ms 间隔；Esc 必须取消拖动。
- **SIM-F-067** 选择关键帧不得自动移动播放头；必须提供显式的 Go to keyframe 操作（按钮与双击），并可通过键盘完成。
- **SIM-F-068** 删除最后一个关键帧必须删除整条轨道；删除轨道后对应属性必须立即恢复基础值。
- **SIM-F-069** 配置编辑必须在 Ready、Preview、Paused、Finished 中可用，在 Playing 中只读；在 Preview / Paused 中编辑后必须立即按当前 `t` 重算。
- **SIM-F-070** 仿真配置必须维护独立的撤销/重做栈，上限 50 步；提供按钮与 Ctrl+Z / Ctrl+Y（焦点位于文本输入框时交还浏览器原生撤销）。每次提交的编辑、拖动、增删轨道/关键帧必须合并为一条记录。
- **SIM-F-071** 配置撤销栈必须在进入仿真页与加载文档时清空，且不得与文档撤销历史共享。
- **SIM-F-072** 在 Preview / Paused / Finished 中撤销或重做后必须立即按当前 `t` 重新求值。

#### 4.2.8 失效轨道

- **SIM-F-080** 目标图元被删除的轨道必须保留为 Dormant，不参与求值，也不阻塞播放。
- **SIM-F-081** 仿真页必须显示 Dormant 轨道数量与明细入口，并提供逐条删除与全部清理操作；清理必须可被配置撤销恢复。
- **SIM-F-082** 编辑器撤销删除并恢复同一图元 Id 后，对应 Dormant 轨道必须自动恢复为 Active。
- **SIM-F-083** 保存文档时不得写入 Dormant 轨道；若存在 Dormant 轨道，Save 必须要求用户明确确认“这些轨道不会被保存”，取消则不得保存。
- **SIM-F-084** 加载外部文档时，指向不存在图元或属性不再是 Float 的轨道必须被剪除并计入警告。

#### 4.2.9 持久化与加载

- **SIM-F-090** 文档 JSON 版本必须为 2，并包含可选 `simulation` 段，包含全局 Loop 设置和轨道数组（目标 `PrimitiveId`、Float 属性名、关键帧数组）。
- **SIM-F-091** 必须拒绝 v1、缺失版本以及高于当前支持上限的版本；只有 v2 文档可被 Import、Load 或样例加载，保存必须统一写 v2。拒绝时必须在 Load/Import 上下文中给出明确原因，且不得删除或改写旧 localStorage。
- **SIM-F-092** 仿真配置必须随现有 Save 写入 `penelopa.document`，并沿用 `penelopa.document.backup`；仿真页 Save 必须与编辑页 Save 使用相同的负载与备份策略，但仿真页仅在 Ready 可用。
- **SIM-F-093** 仿真页 Save 仅允许在 Ready 使用；Preview、Playing、Paused、Finished 中必须禁用并提示先 Stop，防止把动画中间值写入文档。
- **SIM-F-094** 加载文档必须整体替换当前文档与仿真配置；无 `simulation` 段时必须清空配置，并必须清空配置撤销栈。
- **SIM-F-095** 加载确认文案必须说明文档与仿真配置都会被替换。
- **SIM-F-096** 加载时几何与属性继续按严格规则校验；Dormant/孤儿轨道必须在校验前按目标解析剪除并显示警告。Active 轨道结构性非法时必须仍加载文档、整段丢弃仿真配置并显示警告。
- **SIM-F-097** localStorage 写入失败（配额、安全限制、JS 异常）必须显示错误，不得提示保存成功。

#### 4.2.10 校验与错误处理

- **SIM-F-100** 进入 Preview / Playing 或执行 seek / 步进前，必须校验所有 Active 轨道：目标存在、属性为 Float、时间合法、值合法且满足属性约束、插值合法、贝塞尔控制点在 `[0,1]`。
- **SIM-F-101** 编辑时非法值必须在对应字段/行就地拒绝并显示错误；任一 Active 轨道校验失败时必须阻止进入播放/预览，并在汇总区域显示全部阻断原因；当前状态不得改变。存储层不得持有非法配置（见 SIM-F-102）。
- **SIM-F-102** 输入框只允许提交合法时间与值；模型不得持有非法状态。
- **SIM-F-103** Dormant 轨道必须被求值与校验忽略，但必须在页面中提示。
- **SIM-F-104** 仿真运行期异常必须结束会话、恢复基础值并显示错误信息。
- **SIM-F-105** 保存失败必须显示错误；文档和配置保持未保存状态。

## 5. 非功能需求

### 5.1 性能

- **ED-NF-001** 编辑页必须按需渲染：文档、选区或视口变化时才请求重绘；空闲时主线程 CPU 必须低于 5%（空文档）与 50%（500 矩形）。
- **ED-NF-002** 画布必须按物理像素渲染，1 世界单位等于 1 CSS 像素；跨 DPI 显示器移动时必须保持渲染、命中与指针坐标一致。
- **ED-NF-003** 指针移动必须按动画帧节流，不得积压回调；文档加载与保存必须在浏览器主线程可接受的时延内完成。
- **ED-NF-004** 系统必须支持 500 个图元的常规编辑，并允许加载至 10000 个图元的上限；超过文档上限时必须拒绝而不是降级渲染。
- **SIM-NF-001** 在参考环境 Chrome、1440×900 下，500 个图元 + 100 条 Active 轨道同时播放时，5 秒采样平均帧率必须不低于 55FPS。
- **SIM-NF-002** 60 秒循环播放期间不得出现持续内存增长。
- **SIM-NF-003** Ready 与 Stop 后必须回到按需渲染，空闲 CPU 接近零。
- **SIM-NF-004** 仿真播放必须使用只读渲染路径，跳过命中缓冲重建与选择覆盖层；关键帧查找必须使用高效定位（二分）。
- **SIM-NF-005** 20Hz 文本读数不得导致 60FPS 画布掉帧。

### 5.2 可访问性

- **ED-NF-005** 编辑器的选择、移动、删除、撤销/重做、属性编辑、对齐、分组与文档操作必须提供完整键盘路径，或以原生按钮提供等价操作。
- **ED-NF-006** 动态状态、错误与警告必须使用 ARIA live 区域播报；高频读数不得实时播报。
- **ED-NF-007** 路由切换必须管理焦点；导入确认等模态步骤必须把焦点移到可操作控件。
- **ED-NF-008** 必须允许浏览器页面缩放，不得通过 viewport 或脚本阻止；文本与控件必须满足现有对比度基线。
- **ED-NF-009** 所有颜色必须通过 `--penelopa-*` 主题变量或 Atlas `--atlas-*` 覆盖定义，必须支持亮/暗模式；新增控件必须复用现有变量而不是硬编码颜色。
- **SIM-NF-010** 不得自动播放；所有运动必须由用户显式触发。
- **SIM-NF-011** 播放、暂停、停止、重播、Loop、步进、缩放必须使用原生按钮并提供可访问名称。
- **SIM-NF-012** 状态变化、错误汇总与 Dormant 提示必须使用 `aria-live="polite"`；20Hz 时间和数值读数不得实时播报。
- **SIM-NF-013** 画布必须使用 `role="img"` 与描述文本，不得伪装成可交互应用。
- **SIM-NF-014** 所有输入必须有标签；错误必须通过 `aria-describedby` 关联。
- **SIM-NF-015** 关键帧必须提供不依赖拖动的完整键盘路径：检视器列表/表格可编辑时间和值，并提供 Go to。
- **SIM-NF-016** 必须尊重 `prefers-reduced-motion`：不自动播放并提示；用户主动播放仍允许，且随时可暂停。
- **SIM-NF-017** 路由进入时必须把焦点移到页面标题，返回时必须把焦点还给编辑页入口。
- **SIM-NF-018** 新控件必须复用现有 `--penelopa-*` 主题变量并满足现有对比度基线。

### 5.3 兼容性与响应式

- **ED-NF-010** 产品必须运行在支持 WebAssembly 与 WebGL 的现代桌面浏览器上；自动化验收以 Chromium 为准，其他浏览器为手工验证范围。
- **ED-NF-011** 在 700–1440 CSS 像素视口内画布必须保持可用；窄视口允许侧栏压缩，但不得出现横向溢出（1024×768 仿真页为零溢出验收）。
- **ED-NF-012** 应用必须可部署到任意静态主机，并兼容 GitHub Pages 项目站点子路径；路由与资源引用必须基于 `base href`。
- **SIM-NF-020** 主验收视口为 1440×900 与 1024×768；默认布局使用固定像素侧栏与底部时间轴，更窄时允许画布挤压、滚动或折叠，不承诺完整编辑体验。
- **SIM-NF-021** 实现不得要求升级 .NET / SkiaSharp 版本，也不得引入新的前端框架依赖。
- **SIM-NF-022** UI 文案沿用现有应用的英文风格；交付文档使用中文。

### 5.4 安全、隐私与数据完整性

- **ED-NF-013** 应用不得依赖后端服务；导入文档必须按不可信输入处理，执行版本、大小、深度、Id、类型、属性与领域校验；错误消息必须为单行摘要，不得回显堆栈或完整文件内容。
- **ED-NF-014** 保存必须先备份旧负载；导入失败或取消不得改变当前文档；多选编辑、事务取消与导入回滚不得留下部分写入。
- **ED-NF-015** 应用不得收集遥测或向第三方发送文档内容；localStorage 只使用文档键与单槽备份键。

### 5.5 可维护性与测试

- **ED-NF-016** `Penelopa.Core` 不得依赖 Blazor 或 SkiaSharp；`Penelopa.Rendering` 不得依赖 Blazor；Web 层只通过服务与渲染器组合核心能力。
- **ED-NF-017** 构建必须通过格式检查、锁定模式依赖恢复、TypeScript 检查与生成 JS 漂移检查。
- **ED-NF-018** 依赖审计必须在 High/Critical 漏洞时失败；已知中危测试专用依赖必须记录为可接受风险并跟踪迁移。
- **ED-NF-019** README 与交付文档必须描述当前 v2-only 实现，不得链接已删除的过程文档。
- **ED-NF-020** 性能基准必须可通过 `PERF=1` 重复执行，并分别报告 JS tick、.NET frame 与 SKGLView paint。
- **SIM-NF-030** 必须提供 Core 单元测试、bUnit 组件测试、Playwright E2E 测试与性能测试。
- **SIM-NF-031** 新增核心代码行覆盖率必须不低于 90%；`Simulation/` 与 `DocumentSerializer` 以文件级门禁执行，若改动 Rendering，行覆盖率必须保持不低于 85%。
- **SIM-NF-032** E2E 必须覆盖进入/返回、轨道创建、播放/暂停/停止恢复、定位/步进、Loop/Finished/Replay、保存后重新加载、Dormant 清理、默认布局区域与不可关闭行为、分割条键盘调整、折叠恢复、播放中布局调整、100 轨道性能，并断言无控制台错误。
- **SIM-NF-033** README 与交付文档必须与当前实现同步，描述仿真入口、只读画布、v2-only 文档策略与文件 I/O 行为。

## 6. 验收标准

### 6.1 编辑器

1. 添加圆形、矩形、三角形与三种容器；属性面板可编辑、校验并撤销；非法值不写入。
2. 画布可选择、Ctrl 多选、空白清空、连续点击钻取；树与属性面板同步；祖先与后代不会同时选中。
3. 拖拽移动、角柄缩放、空白平移、Ctrl+滚轮缩放与 Fit 行为正确；ESC 精确取消手势。
4. 六方向对齐与分组/取消分组保持世界位置与 Z 序；条件不满足时按钮禁用并显示原因。
5. 多选公共属性显示冲突占位，提交原子写入并只产生一个撤销条目。
6. 方向键、Delete、Ctrl+Z/Y 在画布与输入框中的行为符合键盘边界要求。
7. Save/Load 往返保持文档、选区与仿真配置；旧负载进入备份；存储失败显示错误。
8. Import/Export 往返可用；导入确认显示统计与警告；导入不写 localStorage；一次性撤销导入恢复两套历史。
9. 拖放导入、同文件重选、示例加载与取消行为符合要求。
10. 空状态、错误/状态播报、焦点管理、响应式布局与页面缩放符合可访问性与响应式要求。

### 6.2 仿真

1. 从编辑页顶栏进入 `/simulation`，选中 Rectangle，为 `PosX` 建立 3 个关键帧；拖动播放头时画布与 Current 值同步变化。
2. Play / Pause / Resume / Stop 的状态、按钮与画布行为符合 4.2.5 节状态表；Stop 后基础布局逐值恢复，且不产生编辑器撤销条目。
3. Loop 开启时播放无缝回绕；关闭时到达 `T` 进入 Finished 并保持末帧；Replay 从 0 重新播放。
4. `-1/60s` / `+1/60s` 步进与播放头拖动结果一致，给定 `t` 的求值可重复。
5. 暂停时修改关键帧值/时间/插值，画布与读数立即重算；配置撤销/重做可恢复修改，且不影响文档撤销。
6. 非法起止值、非法时间、越界贝塞尔控制点会阻止播放并显示就地错误。
7. 删除被绑定图元后轨道变为 Dormant；编辑器撤销删除后轨道恢复；加载外部文档时 Dormant 被剪除并显示警告；Save 会提示 Dormant 不会写入。
8. Save 后刷新页面并 Load，轨道、关键帧、插值与 Loop 设置完整复现；仿真只读画布从未改变文档几何。
9. 键盘可完成选择图元、创建轨道、编辑关键帧、定位、播放/暂停/停止的完整路径；状态播报不包含 20Hz 数值刷屏。
10. 500 图元 + 100 条 Active 轨道在参考环境中平均帧率 ≥55FPS；停止后空闲 CPU 接近零。
11. 仿真页默认显示四个必需区域，且不存在关闭入口；键盘调整分割条、折叠并恢复图元树/检视器/时间轴后功能仍可达；播放中折叠或调整布局不会中断播放。

## 7. 非目标

- 世界坐标端点、屏幕空间轨迹换算或轨迹预览。
- 颜色、整数、布尔、字符串属性的动画。
- 逐轨独立循环 / ping-pong；只有全局 Loop。
- 物理、碰撞、惯性、速度积分。
- 表达式、脚本、事件触发、条件状态机或运行时行为断言。
- 把当前预览姿态应用回文档，或把动画中间值保存到文档。
- 视频 / GIF 导出、播放倍速、音频。
- 自动保存、多文档、协同编辑、服务器端存储。
- 全图元时间轴总览、轨道分组/文件夹、时间轴入出点区间。
- 自动关键帧（auto-key）。
- 图形化 cubic-bezier 曲线编辑器；仅提供数值控制点。
- 约束布局、吸附参考线、图层面板、评论与标注。
- 富文本、位图、路径等更多图元类型；插件系统。
- 移动端/触摸优先适配与国际化 UI。
- 轨道超过 100 条同时播放的性能承诺。
- 自动迁移 v1 文档或保留 v1 解析器；v1 数据必须在升级前用旧版本导出。
